> Black Barber | Barbearia

Site desenvolvido como meu primeiro projeto de desenvolvimento web, com o objetivo de praticar HTML5 e CSS3 e aprender a criar páginas modernas e responsivas.

> Acesse o projeto

> [Clique aqui para acessar o site](https://pyerre22.github.io/Black-Barber/)

> Sobre o projeto

O Black Barber é um site fictício de barbearia, criado para praticar a construção de interfaces web. O projeto apresenta os serviços oferecidos, os diferenciais da barbearia, uma seção sobre o estabelecimento e uma área de contato.

> Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — estilização, layout, efeitos visuais e responsividade.
- JavaScript — interação demonstrativa do formulário de contato.
- GitHub Pages — publicação do site na internet.

> Funcionalidades

- Navegação entre as seções da página.
- Apresentação dos serviços e preços.
- Layout adaptado para diferentes tamanhos de tela.
- Formulário de contato demonstrativo.
- Efeitos visuais nos botões e cartões.

> O que pratiquei

- Estruturação de páginas com HTML semântico.
- Criação de layouts com CSS Grid.
- Estilização de formulários.
- Uso de media queries para responsividade.
- Publicação de um projeto com GitHub Pages.
